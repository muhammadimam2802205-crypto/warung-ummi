# Figma Import Kit — Kedai Ummi

Quick start:

```powershell
cd D:\ProjectFlutter\ummie
python -m http.server 8080
```

Buka `http://localhost:8080/figma/`, lalu import URL tersebut dengan plugin **html.to.design**.

- Tokens Studio: [`tokens/kedai-ummi.tokens.json`](tokens/kedai-ummi.tokens.json)
